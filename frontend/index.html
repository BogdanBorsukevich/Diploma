📖 Довідка
Сценарій — вхідні дані для симуляції. Вкажіть параметри та натисніть «Генерувати».
Диспетчер — запуск кластеризації (K-Means / DBSCAN / OPTICS) та перегляд карти кластерів.
Кур'єр — вибір замовлень за власними критеріями (вага, ціна, відстань), прийняття та відмітка виконання.

K-Means: групує замовлення навколо n фіксованих хабів (метод k-середніх). Ідеально для відомої кількості зон.
DBSCAN: виявляє аномальні замовлення (поза зонами обслуговування) за параметрами щільності ε та MinPts.
OPTICS: розширення DBSCAN для районів із різною щільністю забудови.
