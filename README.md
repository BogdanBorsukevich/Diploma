## 📋 Опис системи

Тестувально-навчальний комплекс реалізує два автоматизованих робочих місця:

| АРМ | Функції |
|-----|---------|
| **Диспетчер** | Завантаження/генерація замовлень, просторова кластеризація (K-Means / DBSCAN / OPTICS), інтерактивна карта кластерів |
| **Кур'єр** | Перегляд замовлень свого кластера, багатокритеріальна фільтрація (вага / ціна / відстань), прийняття замовлень, маршрутний лист |

## 🚀 Інструкція з використання

### Крок 1 — Вкладка «Сценарій»
1. Налаштуйте параметри середовища:
   - **Кількість замовлень** — скільки точок доставки генерувати
   - **Кількість хабів** — фіксовані маркети (центри кластерів)
   - **Кількість кур'єрів** — виконавці з різними типами ТЗ
   - **Відсоток аномалій** — «шумові» замовлення поза зонами
   - **Координатні межі** — географічний регіон симуляції
2. Натисніть **«Генерувати сценарій»**  
   _або_ завантажте CSV-файл (колонки: `lat, lon, weight, price`)

### Крок 2 — Вкладка «Диспетчер»
1. Оберіть алгоритм кластеризації:
   - **K-Means** — розподіл навколо n фіксованих хабів (рекомендовано)
   - **DBSCAN** — виявлення просторових аномалій (задайте ε та MinPts)
   - **OPTICS** — адаптивна кластеризація при нерівномірній щільності
2. Натисніть **«Запустити кластеризацію»**
3. Перегляньте результати на інтерактивній карті:
   - Кольорові кружечки = замовлення (колір = хаб)
   - Маркери-крапки = хаби/маркети
   - Червоні квадрати = аномалії (шум)

### Крок 3 — Вкладка «Кур'єр»
1. Оберіть кур'єра зі списку
2. Натисніть **↻** — автоматично завантажить обмеження кур'єра
3. Або задайте критерії вручну:
   - **Максимальна вага** — найбільша допустима вага посилки
   - **Мінімальна ціна** — поріг вартості замовлення
   - **Максимальна відстань** — радіус доставки від хабу
4. Натисніть **«Застосувати фільтр»** — список оновиться
5. Клацніть на рядок таблиці, щоб обрати замовлення
6. Натисніть **«✔ Прийняти»** — статус зміниться на «В роботі»
7. Натисніть **«📋 Маршрутний лист»** — перегляньте прийняті замовлення та відмітьте виконані

### Приклад: генерація сценарію
```bash
curl -X POST http://localhost:5000/api/scenario/generate \
  -H 'Content-Type: application/json' \
  -d '{
    "n_orders": 200,
    "n_hubs": 7,
    "n_couriers": 12,
    "lat_range": [50.30, 50.60],
    "lon_range": [30.40, 30.70],
    "noise_pct": 0.05
  }'
```

### Приклад: кластеризація K-Means
```bash
curl -X POST http://localhost:5000/api/cluster \
  -H 'Content-Type: application/json' \
  -d '{"algorithm": "kmeans"}'
```

### Приклад: фільтрація замовлень кур'єром
```bash
curl -X POST http://localhost:5000/api/courier/orders \
  -H 'Content-Type: application/json' \
  -d '{
    "hub_id": 2,
    "max_weight": 5.0,
    "min_price": 100.0,
    "max_dist": 3.0
  }'
```

## 📐 Математичні основи

### K-Means
Мінімізація WCSS: **J = Σᵢ Σₓ∈Sᵢ |x − μᵢ|²**  
Ітераційно перераховує центроїди до збіжності. Ініціалізація — з координат хабів. Метрика відстані — формула Гаверсина.

### DBSCAN
Класифікує точки на **кореневі** (`|Nε(p)| ≥ MinPts`), **межові** та **шумові**.  
Аномальні замовлення автоматично ізолюються без прив'язки до хабу.

### OPTICS
Еволюція DBSCAN для даних зі змінною щільністю.  
Будує графік досяжності та динамічно адаптується до локальних варіацій.

### Багатокритеріальна фільтрація
**A\* = { aᵢ ∈ A | ∀j: Pⱼ(xᵢⱼ) = true }**  
Кон'юнктивний відбір: замовлення включається лише при виконанні ВСІХ предикатів.  
Складність: **O(n·m)** де n — замовлення, m — критерії.
